# seed

Bootstrap repo for Ultrastable: an idea goes in, a running, self-improving organization comes out.

## North star: criticality
Loops produce more verified deploys than they consume in cost and attention.
- Verified-deploy count rises with no human input
- Spend stays under budget
- Each loop's output feeds another loop

Priority: (1) self-sustaining Ultrastable, (2) cost, (3) new features.

## Mantra (enforced by `scripts/mantra.py`)

**Ship one verified thing. Make the next one cheaper. Start it.**

Each loop ends by running the mantra. Exit 0 = critical; nonzero = the next loop acts.
